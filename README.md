Not Hesaplama Uygulaması

Visual Basic .NET kullanılarak geliştirilen Windows Forms öğrenci not hesaplama uygulaması.

Özellikler

* Öğrenci adı girişi
* Vize ve final notu girişi
* Vize %40, final %60 ağırlıklı ortalama hesaplama
* 50 ve üzeri notlarda geçme, altında kalma kontrolü

Kullanılan Teknolojiler

* Visual Basic .NET
* Windows Forms
* Visual Studio 2013

Hesaplama Formülü

Ortalama = (Vize × 0.40) + (Final × 0.60)
